# bliss-shader-FIXED
fixed version of bliss
en
This is a modified version of Bliss (which is itself a modification of Chocapic13) featuring the following fixes:
 * Fog (filtering has been improved so that blocks no longer blur when looking at the sky near them; this feature is still experimental, so noise and bugs are possible—please report any bugs to ddirz on Telegram)
 * Sunlight in caves (fixed an issue where full sunlight would sometimes appear out of nowhere with the original shader)
 * Flickering shadows at sunset/sunrise (simply disabled shadows for distant clouds)
